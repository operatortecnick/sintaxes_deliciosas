# sintaxes_deliciosas
corretor supremo de programas, funções, aprimoramentos e sinteaxes no geral

## Hermes Lite

Ferramenta interativa para geração de hashes, codificação Base64,
verificação de vazamentos via LeakCheck e envio de mensagens pelo Telegram.

1. Copie `.env.example` para `.env` e preencha as credenciais.
2. Instale as dependências com `pip install -r requirements.txt`.
3. Ao iniciar, as variáveis do arquivo `.env` serão carregadas automaticamente.
4. Execute `python -m hermes_lite.hermes` para iniciar o menu.
